#Rufus Jones Digital Exhibit
A digital exhibit encapsulating a series of physical exhibits about Quaker Rufus M. Jones

##Date Created
2026-05-27

##Author
Owen Decatur
Haverford College
2024-2026 Anne T. Post-Baccalaureate Fellow

##About the project
As part of the Anne T. and J. Morris Evans Post-Baccalaureate Fellowship at Haverford Quaker & Special Collections, Fellows are tasked with curating a physical exhibit featuring the objects from the Rufus M. Jones Papers and other related collections. Using these objects, Fellows have told the story of Rufus Jones and his family, each highlighting different aspects of his life they deemed important.

This digital exhibition is a collection of the four physical exhibits made by students and Fellows from 2018-2026. Each exhibition page attempts to recreate the experience of walking through the Rufus Jones Reading Room and viewing the exhibits on the gallery's walls. This means that the introductory text, the captions, and the order of the objects are all the same as the original curator intended. Included on each exhibition page is a curator's note by Owen Decatur, the Fellow in charge of the creation of this digital exhibit, as he explores the way in which the previous fellows tell the story of Rufus Jones and provides his own context and analysis for their exhibits.

The data set attached to this is a list of the objects present in the exhibit, where they are housed/located, and links to a digital form of the object.

##Data: RMJ_Exhibit_Digital_Asset.csv

This CSV file has 61 items with the following variables:

| Variable | Type | Description|
|----------|------|-------------|
| Exhibit | string | Title of Digital Exhibit |
| Object | string| Name of object |
| Object Type | string| Type of object (letter, photograph...) |
| Call Number | string| Haverford College Quaker & Special Collections Call Number designation or shelf location |
| Link to Object | string |Link to a digital site containing a scan of the physical object |
| Copyright Status | string |Field determining whether object is in copyright |
